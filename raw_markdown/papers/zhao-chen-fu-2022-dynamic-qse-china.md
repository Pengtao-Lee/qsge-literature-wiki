# 动态量化空间均衡模型的理论进展与中国应用

赵扶扬， 陈斌开， 傅春杨

［摘要］ 量化空间均衡是研究新发展格局和区域协调发展等中国重大议题的有力工具。相比于传统的实证方法或理论模型方法，其优势在于具备一般均衡效应，可进行丰富的反事实模拟和政策分析，匹配多维度数据并实现量化研究。近年来，随着量化空间均衡在多领域的深入应用和交叉融合，这一研究范式呈现出“动态化”拓展的重大特征。动态量化空间均衡模型可应用于宏观经济学、金融经济学、环境经济学、房地产经济学等多个研究领域，拓展了这些领域的研究范式和研究视角。本文首先对动态量化空间均衡文献进行综述，详细梳理和讨论了现有理论框架、技术难点和研究议题；进一步地，将这一框架应用于中国宏观经济的空间动态模拟，展示了建模、算法、数据匹配和模拟等过程，分析了空间均衡视角为传统宏观范式提供的理论启示，以及为构建新发展格局提供的政策含义；最后，展望了动态量化空间均衡在诸多中国本土问题上的广阔应用前景。

## 一、引言

党的十九届五中全会提出，要加快构建以国内大循环为主体、国内国际双循环相互促进的新发展格局。构建新发展格局的基础支撑是加快建设全国统一大市场，然而，当前中国国内市场还面临着较强的市场分割，包括由地方保护主义和不公平竞争导致的产品市场分割，以及由户籍制度导致的劳动力等要素市场分割，因此在“空间和区域”的维度上打破市场分割促进产品和要素的区域间流动，是新发展格局研究中的重心。

关于新发展格局的相关研究方兴未艾，研究方法不一而足，其中，量化空间均衡模型（ ）是重要范式之一。这一框架基于经典的贸易模型（， ），由后继文献不断完善并推广至一般的贸易和区域研究中。这一范式的适用性也获得了国内学者的青睐。相比于其他传统研究范式，其核心优势如下： 传统的实证研究范式常用于挖掘两个经济变量的相关或因果关系，但由于不具备一般均衡效应，难以同时对多个经济变量的内生互动关系展开研究。此外，同样由于一般均衡效应的缺失，实证研究在中观、宏观视角上的政策含义往往难以脱离“ 批判”（ ， ）。相比之下，量化空间均衡则可以在一般均衡的框架下讨论多种内生变量的互动关系，同时可以借助丰富的反事实模拟进行政策分析。 传统的理论模型研究范式常用于梳理复杂的经济机制，但与现实的脱离在一定程度上削弱了研究结论的适用性。相比之下，量化空间均衡的优势在于可以匹配多维度现实数据，并实现丰富、可信的量化分析。 中国幅员辽阔、人口众多、市场分割明显，各地区自然资源禀赋、人文环境和经济发展程度的差别之大在世界上是少有的，针对空间维度结构性问题的研究需求迫切，为量化空间均衡的本土化应用提供了肥沃土壤。

随着学科的深入交叉，量化空间均衡被应用于广泛的领域和话题，其自身方法范式也与其他方法范式不断融合演化，最显著的特征就是向着“动态化”发展。那么，动态的量化空间均衡，其必要性在哪里？①对于某些经济学科，动态框架早已成为基本范式，例如，当代宏观经济学和余融经济学格外强调跨期决策，基于空间视角进行的宏观或金融研究（ ， ； ，）在应用量化空间均衡框架时内在地需要向动态拓展。 对于某些研究对象，其自身属性天然包含跨期特征，例如，具有耐用性和投资属性的房地产（ - ， ）、影响代际流动性的教育迁移问题（<sub>Eckert and Kleineberg</sub>，<sub>2021</sub>），这些话题在空间视角下均具有巨大的研究意义，同时又内在地要求动态视角。 对于某些事件，其产生影响的过程可能较为缓慢，导致短期影响和长期影响截然不同，例如，基础设施的空间配置和空间影响（ ， ），环境变化对经济活动空间分布的影响（ ， ），都需要在动态框架下将长、短期分离开进行分析。

本文的核心工作，是对动态量化空间均衡的建模方法和研究议题进行评述。目前，已有文献对量化空间均衡模型进行了综述（ - ， ； ， ；鞠建东和陈骁， ），但主要集中于静态框架。针对动态的量化空间均衡模型，据本文作者所知，还没有中英文文献给出全面且细致的梳理。此外，国内学术界对动态量化空间均衡的应用仍未正式起步<sup>①</sup>。本文的工作则试图填补这两方面空白。

本文首先对量化框架均衡模型的动态化框架进行梳理，包括劳动力动态、资本动态、企业动态等模块，试图在统一的设定和符号体系下勾勒出囊括多数模型的理论框架。其次，对引入空间动态的关键难点进行了解释，并指出空间维度和时间维度相交叠在数值模拟中导致的“维度诅咒”是主要技术难题，尤其是当同一个体同时进行迁移和储蓄时将导致状态空间爆炸。接下来，对动态空间均衡的应用话题进行了归类和综述。本文发现，当今的量化空间均衡模型早已不再是区域经济、城市经济与国际贸易三个领域的专属研究工具其向动态拓展后在宏观经济学，发展经济学，金融经济学、环境经济学、房地产经济学等其他学科中展现出了强大的适用性。

作为应用示例，本文将动态量化空间均衡应用于中国宏观经济和新发展格局的讨论之中。本文在经典宏观经济模型中引入劳动力的空间动态迁移，在建模、算法、数据匹配和模拟等步骤给出了展示并揭示了空间视鱼所赋予宏观经济学的新发现和新启示一方面引入人口迁移后经济系统的收敛速度骤然下降，同时经济系统在收敛至稳态的动态过程中不一定是单调变化的。这些发现对传统宏观理论依赖稳态(平衡增长路径)进行分析的典型范式提出了挑战另一方面本文发现，最终决定经济结构的不是资本积累而是人口分布，在人口逐步聚集的情况下，劳动力的配置效率将进一步提高，各地的人均收入水平也将出现更快的区域收敛。这一发现的政策含义是，中国应摆脱对投资的过度依赖，在旧“人口红利”逐步消散的背景下，通过提高劳动力的配置效率激发新“人口红利”，尤其是引导人口向优势地区高效聚集。

本文后续结构安排如下。第二、三部分为文献综述，其中，第二部分梳理出一个囊括多种动态设定的理论框架，并介绍关键难点与应对方式；第三部分梳理动态量化空间均衡的应用领域与研究话题。第四部分为该框架在中国宏观经济中的应用示例，展示了应用过程以及新方法下的新发现与新启示。第五部分展望动态量化空间均衡在多个中国本土重大问题上的广阔应用前景。

## 二、基本理论框架

本部分对动态化的模块设定进行梳理，试图在统一的设定和符号体系下勾勒出囊括多数模型的理论框架。为了保证理论框架的完整性，本文还会回顾各种动态模块的传统静态设定。<sup>①</sup>

## 1. 劳动力动态

劳动力流动并不是完全充分的，主流文献引入了劳动力ω对地区i的个体性异质性偏好 $ { \varepsilon } _ { i } ^ { \omega }$ ，以及初始位置i和终点位置n之间的迁移成本 $\kappa _ { i n }$ 地区i的劳动力迁移至地区n获得的个体效用为$\smash { \varepsilon _ { n } ^ { \omega } u _ { n } / \kappa _ { i n } \circ \varepsilon _ { n } ^ { \omega } }$ 服从独立且相同的 分布， $\mathrm { F } \left( \varepsilon \right) = \exp \left\{ - \varepsilon ^ { - 1 / \rho } \right\} ; \kappa _ { i n } \geqslant 1$ ，假设劳动力不迁移则不面临迁移成本，即 $\kappa _ { { \scriptscriptstyle i i } , t } = 1$ 。在标准的推导下可以得到从地区i迁移至地区n的家户比例 $D _ { i n }$ ：

$$
D _ {i n} = \left(u _ {n} / \kappa_ {i n}\right) ^ {1 / \rho} / \sum_ {m = 1} ^ {N} \left(u _ {m} / \kappa_ {i m}\right) ^ {1 / \rho}\tag{1}
$$

其中， $1 / \rho$ 表示人口迁移弹性。由不同i和 $n$ 组成的 $D _ { i n }$ 的集合称为“迁移矩阵”。

（ ）无穷期劳动力动态迁移。当前，较为普适的设定是 （ ）给出的框架，该框架在 （ ）的早期工作论文问世后得以推广。劳动力的决策时序为：在t期开始，给定劳动力ω生活在地区i，无法在当期立即迁移；在t期内劳动力 $\omega$ 提供劳动，并选择当期的最优消费；在t期结束时，劳动力 $\omega$ 选择 $t + 1$ 期的工作居住地并完成迁移。用 $\boldsymbol { v } _ { i t } ^ { \omega }$ 表示终生效用：

$$
v _ {i t} ^ {\omega} = \ln u _ {i t} + \max _ {\left\{n \right\} _ {1} ^ {N}} \left\{- \ln \left(\kappa_ {i n, t}\right) + \rho \varepsilon_ {n t} ^ {\omega} + \beta \mathrm{E} _ {t} \left[ v _ {n, t + 1} ^ {\omega} \right] \right\}\tag{2}
$$

其中， $\mathcal { B } \in ( 0 , 1 )$ 表示贴现率， $\kappa _ { i n , t }$ 表示迁移成本 $\ ; \varepsilon _ { n t } ^ { \omega }$ 表示劳动力ω对地区 $n$ 的个体性偏好，服从对任意的 $t \textmd { , } \omega$ 和n都独立且相同的 类极值分布 $\operatorname { F } ( \varepsilon ) = \exp \left\{ - e ^ { - ( \varepsilon + \bar { \gamma } ) } \right\}$ ，γ为 - 常数。

令 $V _ { \ast t } = \mathrm { E } _ { \varepsilon } \big [ v _ { i t } ^ { \omega }$ 表示劳动力ω观察到 $\varepsilon _ { n t } ^ { \omega }$ 具体实现值之前的预期效用，可证明 $V _ { i t }$ 服从递归形式：

$$
V _ {i t} = \ln u _ {i t} + \rho \ln \Sigma_ {n = 1} ^ {N} \left(\exp \left\{\beta \mathrm{E} _ {t} \left[ V _ {n, t + 1} \right] \right\} / \kappa_ {i n, t}\right) ^ {1 / \rho}\tag{3}
$$

同时，从地区i迁移至地区n的家户比例 $D _ { i n , t + 1 }$ 服从如下表达式：

$$
D _ {i n, t + 1} = \left(\exp \left\{\beta \mathrm{E} _ {t} \left[ V _ {n, t + 1} \right] \right\} / \kappa_ {i n, t}\right) ^ {1 / \rho} / \sum_ {m = 1} ^ {N} \left(\exp \left\{\beta \mathrm{E} _ {t} \left[ V _ {m, t + 1} \right] \right\} / \kappa_ {i m, t}\right) ^ {1 / \rho}\tag{4}

可以看到，（ ）式的总体形式和经济含义与（ ）式非常相似：决定人口迁移和人口分布的首先是各地区带来的效用 $V _ { i t }$ 和迁移成本 $\boldsymbol { \kappa } _ { i n , t }$ ，其次，迁移弹性 $1 / \rho$ 也起到了决定性作用。

## 2. 资本动态

文献在静态框架中往往将资本解读为土地或建筑物，在物理空间的限制下这类资本无法在短期发生变化且无法跨地区移动，因此，不同地区的这一类资本供给可假设为给定。 （ ）引入了一般意义上的资本，且资本可以跨地区流动，不同地区的资本回报率决定了资本的空间分布，但资本在整个经济系统的总供给量仍然是给定的。当前，越来越多的动态量化空间文献引入了资本的内生动态积累，本文提炼出如下三类典型的投资行为设定。

（ ）代表性个体的投资行为。 （ ）提出，当市场是完全竞争、完备，且经济个体具有完全理性预期时，不存在市场失灵，分散经济等同中央计划者经济。中央计划者的目标函数为：

$$
W _ {t} = \sum_ {i = 1} ^ {N} \phi_ {i} l _ {i t} V _ {i t}\tag{11}
$$

其中， $l _ { i t }$ 为地区i的人口数， $V _ { i t }$ 为地区i单个个体的终生效用，ϕ 为中央计划者对不同地区赋予的权重。中央计划者以（ ）式为目标，在各类经济和资源的约束下选择各地最优的资本积累 $k _ { i t } ^ { \phantom { } } ($ 。

需要强调的是，上述设定方式往往将各地人口视为固定。一旦引入人口流动，中央计划者需要将人口流动对经济增长和经济活动区域分布的影响考虑在内，其决策与分散经济将会存在差异，中央计划者的解法将不再适用。此外，当各地人口发生变动时，中央计划者对各地的权重 $\phi _ { i }$ 也需要进行动态调整，这对参数 $\phi _ { i }$ 的校准带来了较大挑战。

（ ）假设整个经济只有一个代表性消费者，却可以同时在不同地区提供劳动和积累资本，这种设定则不存在多个地区经济个体的效用加总和权重设定难题。

（ ）地区专有投资者。 （ ）假设地区i的资本 $k _ { i t }$ 是由当地专门从事投资活动的投资者进行积累的。投资者不能迁移，所积累资本主要被解读为建筑物，也不能跨区域自由流动。

$\Pi _ { i t }$ 表示投资者给自身或其他股东的实际分红之和，投资者的目标是最大化未来各期 $\Pi _ { i t }$ 的预期贴现之和，假设目标函数为：

$$
\max _ {\Pi_ {i t}, k _ {i, t + 1}} \mathrm{E} _ {0} \sum_ {t = 0} ^ {\infty} \beta^ {t} [ (\Pi_ {i t}) ^ {1 - \psi} - 1 ] / (1 - \psi)\tag{12}
$$

地区i投资者的预算约束可写为 $p _ { i t } \Pi _ { i t } + p _ { i t } [ k _ { i , t + 1 } - ( 1 - \delta ) k _ { i t } ] = r _ { i t } k _ { i t }$ ，其中， $\delta \in ( 0 , 1 )$ 表示资本折旧率， $r _ { i t }$ 表示名义资本回报率。在常规的求解之下，可以得到投资者分红 $\Pi _ { i t }$ 和新形成的资本存量$k _ { i , t + 1 } ,$ ，分别为本期总资产 $( 1 - \delta + r _ { i t } / p _ { i t } ) k _ { i t }$ 的比例分配：

$$
\Pi_ {i t} = \xi_ {i t} (1 - \delta + r _ {i t} / p _ {i t}) k _ {i t}\tag{13}
$$

$$
k _ {i, t + 1} = (1 - \xi_ {i t}) (1 - \delta + r _ {i t} / p _ {i t}) k _ {i t}\tag{14}
$$

比例 $\xi _ { i t }$ 的动态演化方程为：

$$
\left(\xi_ {i t}\right) ^ {- 1} = 1 + \beta^ {1 / \psi} \left\{\mathrm{E} \left[ \left(1 - \delta + r _ {i, t + 1} / p _ {i, t + 1}\right) ^ {1 - \psi} \left(\xi_ {i, t + 1}\right) ^ {- \psi} \right] \right\} ^ {1 / \psi}\tag{15}
$$

（ ） 框架下的储蓄与投资行为。两期 的框架中，个体只有一次储蓄行为，因此，不必像前两种方式一样将迁移与储蓄决策分离，可假设经济个体同时具备动态迁移和动态储蓄行为。

（ ）假设经济个体在青年之初完成迁移后，在青年时期获得劳动收入 $w _ { n t }$ 一部分用于青年时期消费 $\boldsymbol { e } _ { n t } ^ { Y }$ ，一部分用于储蓄 $s _ { n t } ;$ ；并在老年时期以 $r _ { i , t + 1 }$ 的名义净回报率获得资本收入，用于老年时期的消费 $e _ { n , t + 1 } ^ { O } { } _ { \mathrm { ~ } }$ 。因此，经济个体在完成迁移后的最优消费—储蓄问题可写为：

$$
\max _ {e _ {n t}, e _ {n, t + 1}, s _ {n t}} \left\{u _ {n t} (e _ {n t} ^ {Y}, p _ {n t}) + \beta \mathrm{E} _ {t} [ u _ {n, t + 1} (e _ {n, t + 1} ^ {O}, p _ {n, t + 1}) ] \right\}\tag{16}
$$

在常规的求解之下，可以得到两期实际消费支出恰是青年时期劳动收入的比例分配：

$$
e _ {n t} ^ {Y} = \xi_ {n t} (r _ {n, t + 1}, p _ {n t}, p _ {n, t + 1}) y _ {n t}\tag{17}
$$

$$
e _ {n, t + 1} ^ {o} = \left(1 + r _ {n, t + 1}\right) \left[ 1 - \xi_ {n t} (r _ {n, t + 1}, p _ {n t}, p _ {n, t + 1}) \right] y _ {n t}\tag{18}
$$

其中， $\xi _ { { \scriptscriptstyle n t } } ( r _ { { \scriptscriptstyle n } , t + 1 } , p _ { { \scriptscriptstyle n t } } , p _ { { \scriptscriptstyle n } , t + 1 } )$ 表示青年时期的消费率，具体函数形式取决于间接效用 $u _ { n t }$ 的形式。

## 3. 企业动态

（ ）基础静态设定。企业的主要行为是从事产品的生 $\vec { \cal J } ^ { \pm }$ 。用符号j标记地区i的不同企业，在不同语境下，j或可表示不同行业，或可表示不同的个体异质性企业。在最优生产决策下，处于地区i的企业j在t期的出厂价格 $\tilde { p } _ { i t } ^ { j }$ 依赖于当期当地一篮子要素成本 $\boldsymbol { x } _ { i t } ^ { j }$ ：

$$
\tilde {p} _ {i t} ^ {j} = m k u p \cdot x _ {i t} ^ {j}\tag{19}
$$

其中， $m k u p$ 表示企业的价格加成率，当企业有垄断定价能力时， $m k u p = \sigma / ( \sigma \mathrm { ~ - ~ } 1 )$ ，当完全竞争时， $m k u p = 1$ 。如果生产函数是多种要素和中间品的<sub>Cobb-Douglas</sub>形式，令 $\boldsymbol { \phi } _ { i t } ^ { h }$ 表示地区i第h种要素或中间品价格 $\boldsymbol { \mathscr { \mu } } ^ { j h } \in ( 0 , 1 )$ 表示第h种要素或中间品在j类企业生产函数的产出弹性，则有：

$$
x _ {i t} ^ {j} \propto \left[ \prod_ {h} (\phi_ {i t} ^ {h}) ^ {\mu^ {j h}} \right] / z _ {i t} ^ {j}\tag{20}
$$

如果企业j属于可贸易品行业 $( j = T , T$ 代表可贸易），则地区n生 $\vec { \cal J } ^ { \pm }$ 的可贸易品卖到地区i的价格 ${ \boldsymbol { p } } _ { n i , } ^ { T }$ ，以及其在地区n的出厂价格 $\tilde { p } _ { n t } ^ { T }$ 之间，存在运输成本之间的差别 $: \boldsymbol { p } _ { n i , t } ^ { T } = \tau _ { n i , t } \tilde { p } _ { n t \circ } ^ { T } \tau _ { n i , t } - 1 \geqslant 0$ 表示地区n的<sub>1</sub>单位产品运输至地区i需要支付的成本，如果在当地销售，则不面临运输成本，即 $\boldsymbol { \tau } _ { i i , t } =$ 。若企业j属于不可贸易品行业，则不会 $\vec { \cal J } ^ { \pm }$ 生运输成本。

除了典型的生产行为之外，企业还具备多种潜在的行为，这些行为往往具备动态特征，本文提炼出量化空间均衡模型中的如下企业动态行为设定。

（ ）企业进入与选址。 （ ）在垄断竞争框架下考虑了企业的动态进入问题。当企业具有垄断定价能力时，其每期都可获得正的垄断利润 $\pi _ { i t } ^ { j } = \big ( \tilde { p } _ { i t } ^ { j } - x _ { i t } ^ { j } \big ) q _ { i t } ^ { j } = x _ { i t } ^ { j } q _ { i t } ^ { j } / \big ( \sigma \mathrm { ~ - ~ } 1 \big )$ 。令 $\lambda _ { \mathit { i t } }$ 表示地区i的企业进入成本，当该地区该行业企业进入达到均衡时，企业进入成本将等于企业市值：

$$
\lambda_ {i t} = \mathrm{E} _ {t} \sum_ {s = t} ^ {\infty} \beta^ {s - t} \pi_ {i s} ^ {j}\tag{21}
$$

当然，上述企业进入的设定来自经典的宏观框架，但在量化空间均衡的框架下，企业进入的动态行为可以进一步拓展为动态选址和迁移行为。 （ ）套用了（<sub>2010</sub>）、<sub>Caliendo et al</sub>（<sub>. 2019</sub>）中劳动力动态迁移的设定，假设企业的值函数为：

$$
\Xi_ {i t} ^ {j} = \pi_ {i t} ^ {j} + \max _ {\{n \} _ {1} ^ {N}} \left\{- 1 _ {(n \neq i)} \cdot \lambda_ {n t} + \vartheta \varepsilon_ {n t} ^ {j} + \beta \mathrm{E} _ {t} \left[ \Xi_ {n, t + 1} ^ {j} \right] \right\}\tag{22}
$$

其中， $\varepsilon _ { n t } ^ { j }$ 表示企业j对地区n的个体性利润冲击，服从类似于（ ）式中 $ { \varepsilon ^ { j } } _ { n t }$ 的极值分布， $1 _ { ( n \neq i ) }$ 为判断条件，只有下一期的选址与本期所在地不一致时才等于1.才会支付进入成本 $\lambda _ { n t ^ { \circ } }$ 、可以看到，（ ）式与（ ）式结构相似，唯一不同的是企业迁移成本 $\lambda _ { n t }$ 与劳动力迁移成本 $\ln \left( \kappa _ { i n , t } \right)$ ，前者只依赖于迁入地而不依赖于迁出地。可以得到从地区i迁移至地区 $n$ 的企业比例 $G _ { i n , t + 1 }$ 服从如下表达式：

$$
G _ {i n, t + 1} = \left(\exp \left\{\beta \mathrm{E} _ {t} \left[ \mathrm{E} _ {\varepsilon} \left[ \Xi_ {n, t + 1} \right] \right] - \lambda_ {n t} \right\}\right) ^ {1 / \vartheta} / \sum_ {m = 1} ^ {N} \left(\exp \left\{\beta \mathrm{E} _ {t} \left[ \mathrm{E} _ {\varepsilon} \left[ \Xi_ {m, t + 1} \right] \right] - \lambda_ {m t} \right\}\right) ^ {1 / \vartheta}\tag{23}
$$

（3）技术研发、在经典的宏观内生增长文献中企业的技术水平可以通过研发实现内生积累一般来讲，技术水平不仅依赖于以往的技术存量，还依赖于新增的研发支出。用 $\eta _ { i t } ^ { j }$ 表示地区i的企业j在时期t的研发支出，则技术水平 $\boldsymbol { z } _ { i t } ^ { j }$ 可以服从如下动态过程：

$$
z _ {i t} ^ {j} = g (z _ {i, t - 1} ^ {j}, \eta_ {i t} ^ {j})\tag{24}
$$

企业的动态研发问题可写为，在（ ）式的约束下，最大化如下目标函数：

$$
\max _ {\{z _ {i s} ^ {j}, \eta_ {i s} ^ {j} \} _ {s = t} ^ {\infty}} \mathrm{E} _ {t} \sum_ {s = t} ^ {\infty} \beta^ {s - t} \left[ \pi_ {i s} ^ {j} (z _ {i s} ^ {j}) - \eta_ {i s} ^ {j} \right]\tag{25}
$$

在上述问题中，企业在选择最优研发支出 $\eta _ { i t } ^ { j }$ 时，不仅需要考虑技术水平 $\boldsymbol { z } _ { i t } ^ { j }$ 对当期利润的影响，还需要考虑对未来利润的影响，问题复杂度较高。 - （ ）进行了巧妙化简，假设除一般生产要素外，企业还需要租赁土地开展生产，地租用 $R _ { i t } ^ { j }$ 表示。而 $\boldsymbol { \pi } _ { \dot { \dot { u } } } ^ { j }$ 在此时表示仅扣除可变要素成本，并未扣除固定的地租成本时的利润。企业在t期之初，给定现有技术存量 $z _ { i , t - 1 } ^ { j }$ ，对能够获得的利润 $\boldsymbol { \pi } _ { i t } ^ { j } \left( \boldsymbol { z } _ { i , t - 1 } ^ { j } \right)$ 作出预估，竞争地块并支付地租 $R _ { i t } ^ { j } ; t$ 期之内，进行研发支出 $\eta _ { i t } ^ { j }$ ，将技术水平从 $z _ { i , t - 1 } ^ { j }$ 升级为 $\boldsymbol { z } _ { i t } ^ { j }$ ，实际获得的利润为 $\pi _ { i t } ^ { j } \left( z _ { i t } ^ { j } \right) _ { \mathsf { c } }$ 。此时企业的目标函数写为：

$$
\max _ {\left\{z _ {i s} ^ {j}, \eta_ {i s} ^ {j} \right\} _ {s = t} ^ {\infty}} \mathrm{E} _ {t} \Sigma_ {s = t} ^ {\infty} \beta^ {s - t} \left[ \pi_ {i s} ^ {j} \left(z _ {i s} ^ {j}\right) - \eta_ {i s} ^ {j} - R _ {i s} ^ {j} \right]\tag{26}
$$

进一步地，假设企业对地块的竞争是通过价高者得的拍卖形式，那么给定技术存量 $\boldsymbol { z } _ { i t } ^ { j }$ ，地租将“榨干”企业利润<sub>E</sub> $\begin{array} { r } { \left[ \pi _ { i , t + s } ^ { j } \left( z _ { i t } ^ { j } \right) \right] = \mathrm { E } _ { t } \left[ R _ { i , t + s } ^ { j } \right] , \forall s > 1 } \end{array}$ 。 因此，企业在选择最优研发支出 $\eta _ { i t } ^ { j }$ 时，由于 $R _ { i t } ^ { j }$ 已经依据 $\pi _ { \dot { u } } ^ { j } \left( z _ { i , t - 1 } ^ { j } \right)$ 支付完成，其仅需考虑技术进步对当期利润 $\pi _ { \dot { u } } ^ { j } \left( z _ { \dot { u } } ^ { j } \right)$ 有多少额外收益，无需考虑对未来利润的影响。此时，（ ）式的跨期问题退化为重复的单期静态问题，并无需考虑 $R _ { i t } ^ { j }$ 的影响：

$$
\max _ {z _ {i t} ^ {j}, \eta_ {i t} ^ {j}} \pi_ {i t} ^ {j} (z _ {i t} ^ {j}) - \eta_ {i t} ^ {j} - R _ {i t} ^ {j} \sim \max _ {z _ {i t} ^ {j}, \eta_ {i t} ^ {j}} \pi_ {i t} ^ {j} (z _ {i t} ^ {j}) - \eta_ {i t} ^ {j}\tag{27}
$$

（<sub>4</sub>）技术扩散。<sub>Desmet</sub> <sub>and</sub> <sub>Rossi</sub>-<sub>Hansberg</sub>（<sub>2014</sub>）刻画了同一行业 j 内不同地点 i 的企业的扩散过程。简化假设每个行业 j每个地点 i只有一类代表性企业，则技术扩散过程可以用如下方程表示：

$$
z _ {i t} ^ {j} = \max _ {\{n \} _ {n = 1} ^ {N}} \left\{e ^ {- \gamma \cdot d _ {i n}} z _ {n t - 1} ^ {j} \right\}, \gamma > 0\tag{28}
$$

其中， $d _ { i n }$ 表示地区i和地区n企业之间的距离。显然，技术的扩散程度受到距离的影响，技术水平的高低容易在不同区域之间呈现聚集特征。

<sub>Liu and Wang</sub>（<sub>2020</sub>）刻画了同一个地区i内不同企业 $\cdot j$ 之间的技术扩散。用匹配函数 $m _ { i } \left( j , j ^ { \prime } \right)$ 表示地区i中企业j和 $j ^ { \prime }$ 在当地企业网络中关系的远近，则企业j生产技术的演化方程可写为：

$$
z _ {i t} ^ {j} = \left[ g \left(z _ {i, t - 1} ^ {j}, \eta_ {i t} ^ {j}\right) + \chi \Sigma_ {j ^ {\prime}} m _ {i} (j, j ^ {\prime}) g \left(z _ {i, t - 1} ^ {j ^ {\prime}}, \eta_ {i t} ^ {j ^ {\prime}}\right) \right] ^ {\alpha}, \alpha \leqslant 1, \chi > 0\tag{29}
$$

显然，企业 j的生产技术 $\boldsymbol { z } _ { i t } ^ { j }$ 不仅取决于自身的技术存量 $z _ { i , t - 1 } ^ { j }$ 和研发投入 $\eta _ { i t } ^ { j }$ ，也通过企业网络$m _ { i } \left( j , j ^ { \prime } \right)$ 依赖于其他企业的技术进步过程，（ ）式本质上是（ ）式的拓展。

## 4. 贸易与均衡

区域贸易往往不具备动态特征，然而区域贸易是量化空间均衡模型的“基石”。即便向动态化拓展之后，区域贸易也是不可忽略的模块。区域贸易的建模以 （ ）和（ ）为代表，两种方式殊途同归，此处不作展开介绍。令 ${ \boldsymbol { p } } _ { n i , } ^ { T }$ 表示地区 $n$ 生 $\vec { \cal J } ^ { \pm }$ 的可贸易品卖到地区i的价格，则地区i对地区 $n$ 可贸易品的最优支出占地区i总支出的比例为：

$$
S _ {n i, t} = \left(p _ {n i, t} ^ {T}\right) ^ {- \theta} / \sum_ {m = 1} ^ {N} \left(p _ {m i, t} ^ {T}\right) ^ {- \theta}\tag{30}
$$

其中，参数 $\theta > 0$ ，代表贸易弹性。由不同i和n组成的 $S _ { n i , t }$ 的集合称为“贸易矩阵”。

可贸易品的市场出清条件，是地区 $n ^ { \stackrel { \triangledown } { \vec { J } ^ { E } } }$ 品的销售额应等于其他各个地区对其支出之和。在没有行业间生产网络的模型中出清条件为 $\begin{array} { r } { \tilde { p } _ { n t } ^ { T } q _ { n t } ^ { T } = \sum _ { i = 1 } ^ { N } S _ { n i , t } { \bullet \varphi ^ { T } \bullet ( \sum _ { j } \tilde { p } _ { i t } ^ { j } q _ { i t } ^ { j } ) } } \end{array}$ ，其中， $\tilde { p } _ { n t } ^ { T } q _ { n t } ^ { T }$ 表示地区 $n$ 可贸易品的总产值； $\Sigma _ { j } \tilde { p } _ { i t } ^ { j } q _ { i t } ^ { j }$ 表示地区i所有行业的总收入，也是地区i的总支出 $; \varphi ^ { T }$ 表示总支出中可贸易品占比， $\boldsymbol { \varphi } ^ { T }$ 的大小取决于效用函数和投资函数中可贸易品与不可贸易品的相对重要程度。

当然，不同场景下模型的设定不一而足，还有更多的动态设定形式，表<sub>1</sub>做了梳理和归类。

## 5. 主要挑战及应对方式

仅仅数年之前，量化空间均衡相关文献都未能大批量向“时间动态维度”进军（- ， ）。其关键技术难点在于，“维度”问题制约了动态量化空间均衡的快速发展和广泛应用，在考虑时间动态时不可忽略经济个体的“理性预期”行为，但众多求解方法只能给出均衡条件，却难以在一般的假设下求出显式解，这迫使学者们求助于计算机和数值模拟。随着模型的拓展、变量的增多，需要的计算机算力和内存容量呈指数速度增加，导致了众所周知的“维度诅咒”。量化空间模型天然包含地理空间维度，在引入动态后，会存在空间维度和时间维度的交叠，变量数十，数百倍增加带来的维度问题将不可避免。

更具挑战的问题是，经济个体可能同时存在“动态迁移”行为和“动态投资储蓄”行为。由于财富是由历史各期积累而来，不同个体所拥有的财富依赖于该个体在历史中经历过的地区，导致个体异质性会随着时间的推移爆发式地扩张。以一个简化例子说明：经济系统由N个地区组成，如果第期各地区内部的个体都是同质的，则该期至少存在N类异质性个体；在第 期，任一地区i内有来自N个不同地区的个体这些个体虽然在本期都处于地区i却因为第1期所在区域的差异影响了在第 期财富水平的高低，因此，该期至少存在N<sup>2</sup>类异质性个体；在第 期，异质性个体的类别数将扩展为N<sup>3</sup>。随着时间的推移，每个地区内都有无穷多种经济个体，这些个体行为决策不尽相同。此时，整体经济系统的状态空间将扩张至无穷维度，“维度诅咒”将进化为“维度毒咒”。本文将上述问题简称为“财富分布的历史路径依赖性”问题。

应对“维度”问题和“财富分布的历史路径依赖性”问题，文献主要采用了三种模型简化设定。进行直接的维度化简。例如， （ ）设置了不同地区固定资产的外生持有，从而将资本的积累外生化或静态化； - （ ）假设劳动力在不同地区自由流动，使得个体在空间维度的异质性得到大幅度压缩。 将投资储蓄的跨期决策在一定程度上独立出来。例如， （ ）假设家庭只提供劳动并可以进行迁移，而资本则由单独的地区代表性投资者进行积累，且投资者无法进行迁移； （ ）在整个经济中设定了一个代表性消费者，该个体可以同时在不同地区提供劳动和积累资本。 打破理性预期行为中“当前行为影响未来”而“未来境况影响当前决策”的循环反馈。一方面是通过合理设定使得经济个体的当期决策不会影响其未来，例如， （ ）、 （ ）刻画的劳动力跨期迁移；另一方面是通过合理设定使得经济个体的当期决策无需考虑未来，例如， -（ ）刻画的企业研发投资行为，以及 （ ）刻画的劳动力迁移行为。

“简化模型”并不是量化空间文献向动态迈进的唯一途经，有相当多的文献也在“优化算法”方面作出了努力。由于不同算法技术性过强且差异较大，本文仅能就相关内容进行一个初步、粗劣且不完善的介绍<sup>①</sup>。

## 2. 劳动力市场

劳动的空间分布原本就是量化空间均衡的传统话题。在动态视角下， （ ）、（ ）等文献为劳动力迁移提供了更丰富的机制分析和量化分析。此外，劳动力市场又是宏观经济学、发展经济学、劳动经济学的重要话题 ，成为了交叉领域的连接桥梁。

失业问题是宏观经济学与动态量化空间均衡的交叉领域。 （ ）观察到失业率在地区间存在巨大的异质性，随后通过劳动力市场的“搜寻—匹配”框架在模型中引入了内生失业，劳动力市场的匹配摩擦导致高生产率的雇主过于重视彼此之间的聚集，使得不同企业雇主的分布过于分化，最终带来了失业率的空间异质性，Caliendoetal(2019)则假设劳动力不仅可以在行业间转移，还可以自主选择退出劳动力市场并接收固定的补助，从而讨论了中国贸易冲击对美国就业的影响。

收入分配公平是劳动经济学、发展经济学等领域与动态量化空间均衡的交叉领域。（ ）探讨了不同技能水平劳动力的收入差距，以及该差距受技能偏向性技术进步的影响。- （ ）认为，更好的居住环境会在未来带来更好的教育和工作机会，那么个体对居住地的选择存在一种跨期权衡即当令住房成本高低以及未来机会好坏之间的权衡因此低收入群体往往不得已选择环境更差且未来机会更差的地区居住，这导致了持续性的收入不平等。

代际流动性是收入分配领域中的重要子话题。<sub>Eckert and Kleineberg</sub>（<sub>2021</sub>）观察到美国的教育质量在不同街区差异很大，并刻画了一个代际迁移模型，发现教育程度和收入在代际之间存在明显持续性。该文研究了不同区域学校建设资金均等化的政策，发现尽管这一政策会直接给低收入和低教育程度家庭带来利好，但在一般均衡中，低收入和低教育程度家庭反而会重新搬迁至基础教育质量更低的地区，抑制了教育均等化的最终效果。 （ ）关注了劳动者所属职业的代际变化，及其与收入不平等的互动关系和影响因素，发现教育均等化改革可以促进代际职业流动性但会扩大收入不平等，贸易自由化会抑制职业和区域的流动性并扩大收入不平等，迁移成本的降低则可以促进区域流动性并减缓收入不平等，但抑制代际职业流动性。

## 3. 企业动态

企业动态的最直接刻画是企业在不同地区的选址和进入退出。 （ ）使用（ ）中劳动力动态迁移的方式引入企业的动态选址，研究了美国 年以来的贸易保护政策是否能导致制造业企业回流，发现贸易保护政策仅能缓解制造业企业数量的下降，但无法从根本上扭转下降的趋势，且贸易保护政策短期效应较低，远远小于长期效应。企业数量增加也会推动经济增长， （ ）认为这一效应是解释地区经济增长差异的重要因素，而不是企业规模或企业寿命，新企业抬高工资并吸引劳动力流入，这进一步增加了当地对产品和服务的总需求，带来了更多新增企业，形成了正反馈循环。

企业动态还体现在知识和技术在企业间的动态扩散。 - （ ）中，除了自主创新外，技术扩散也是企业获取新技术的重要途经，企业间距离的远近决定了技术扩散的难易程度，这为经济的积聚和规模效应提供了微观基础。 （ ）在跨国、跨行业的贸易框架下引入了技术的研发和动态扩散，发现贸易成本降低促进研发活动和比较优势的再配置，而技术扩散则会放大上述贸易引致的专业化效应。 （ ）在跨国企业国际投资的研究中，建立了母公司和子公司的技术联系，即子公司的生产率不仅取决于当地的生产率水平，更取决于母公司所在地的技术水平，从而刻画了跨国企业对外直接投资带来的技术溢出效应。

许多动态因素在企业生产网络中会得到更多的经济含义。例如， （ ）在讨论中国贸易冲击的动态影响时，引入了 个行业的投入产出结构，这成为美国非制造业就业扩张的重要渠道之一：由于从中国进口的廉价制造业产品是非制造业的重要中间品，降低了美国非制造业的生产成本，导致非制造业的快速扩张。当然，网络经济学是一个较为独立的领域，量化空间均衡和网络经济学尚未呈现出明显的汇流趋势本文不对此开展介绍。

## 4. 房地产市场与金融市场

现实中，用地管制和房地产管制在不同地区存在极大的异质性，越是高收入地区、高房价地区，管制越严格。 （ ）认为美国部分州日趋严格的用地管制，对劳动力与资本的分布产生了巨大的再配置影响，这对于美国逐步下滑的生产率和经济增速具有强大解释力，也同样有助于理解诸如加州和纽约州等高收入州快速上涨的房价。在这一框架下，<sub>Babalievsky et al</sub>（<sub>. 2022</sub>）进一步探讨了商业地产管制对产出、福利以及劳动力和经济活动区域分布的影响。（ ）认为美国高收入地区的用地管制对劳动力迁移起到了“壁垒”作用，发现如果将加州 年的管制程度降低至其 年水平，将对劳动的区域配置产生巨大作用，加州人口将上升 ，加州和美国其余地区的收入差距和房价差距将分别下降<sub>3.7%</sub>和<sub>2.7%</sub>。

（4）研究启示。对研究范式的启示是，传统宏观理论依赖经济稳态（或平衡增长路径）进行分析的意义可能会被削弱。一是因为引入人口迁移后经济收敛速度骤然下降，经济从初始状态收敛至稳态附近耗时甚久；二是经济系统在收敛至稳态的动态过程中不一定是单调变化的（从图2中H省经济总量先上升后下降的现象可知），因此，稳态的相对关系不一定能代表动态的相对关系。政策含义方面有两点启示：一是最终决定经济结构的不是资本而是人口，中国经济发展应摆脱对投资的过度依赖，在旧“人口红利”逐步消散的背景下，通过提高劳动力的配置效率激发新“人口红利”，尤其是引导人口向优势地区高效聚集；二是在人口逐步聚集的情况下，各地区的经济总量不仅不会收敛反而趋于发散，因此，地方政府在经济治理中应减少对经济总量目标的过度关注，更多地用人均GDP和人均可支配收入等人均指标替代总量指标。

## 五、结论与展望

近年来，量化空间均衡模型得到了迅速的发展，也逐步获得国内学术界的认可和应用。随着这一方法在多个学科的深入应用和交叉融合，这一研究范式呈现出“动态化”特征。展望未来，动态量化空间均衡框架在中国经济问题研究中具有重大的应用前景。一方面，中国幅员辽阔、人口众多，加之地区间产品市场和要素市场存在的分割现象，中国经济对于“空间和区域”的研究视角具有迫切需求。另一方面，中国是一个仍处在结构转型中的大型发展中经济体，相比于已经处于平衡增长路径的发达经济体，中国当前所处经济发展阶段对“动态”研究视角具有更强的内在要求。

本文以中国四个重大问题为例，展望动态量化空间均衡在中国经济中的应用前景。①构建新发展格局和国内大市场建设。“空间格局”是新发展格局内涵中最重要的一个“格局”维度，当前中国内部存在的市场分割为建成超大规模国内大市场带来了巨大挑战。因此，研究产品，劳动力，资本及其他要素在不同地区的动态流动具有重要的理论意义、现实涵义和政策价值。 空间视角下的宏观经济问题。由于中国仍处于社会主义初级阶段的本质特征许多中国宏观经济问题往往需要与发展经济学、产业经济学相结合，既要兼顾宏观经济增长等总体性问题，又要注重区域协调发展、产业结构升级、共同富裕、国土空间格局等诸多结构性问题，量化空间均衡在其中可能发挥巨大作用。 房地产的地区间分化问题。近 余年来，中国房地产市场的突出特征之一是房价增速的区域间分化，巨大的增速差异难以用人口流动或土地供给全部解释，存在广阔的探索空间。将量化空间均衡用于研究中国房地产的空间特征，不仅有利于制定“因城施策”的房地产政策，更有助于防范金融风险的空间传染、治理土地财政和地方债务等。 “双碳”政策的路径设定和潜在影响。环境保护与“双碳”目标是中国贯彻新发展理念的重要内容。环境状态的演化往往较为缓慢，需要动态视角。同时，在建设优势互补的区域分工格局过程中，减排压力在不同区域是不同的，同样需要空间视角，量化空间均衡的应用将有助于地区间“碳补偿”“碳交易”等措施的研究和制定评估各类政策的短期和长期效果，实现经济效益和能耗成本的双重目标。

当然由于动态量化空间均衡高度依赖计算机模拟和数据的匹配计算机软硬件的算力不足，空间维度多期数据的缺失均会限制该范式的自由拓展。不过，计算机算力和数据可得性都在快速发展和完善中，此外，精巧的模型设定、算法设计也都可以缓解上述两方面的限制。可以预见，动态量化空间均衡与中国问题研究的关系，在长期并不仅是方法应用，还将出现研究范式对中国特征的适应性演化与拓展，从而发挥更大的研究作用。

# Dynamic Quantitative Spatial Equilibrium: Literature Review and Application in China ZHAO Fu<sup>-</sup>yang<sup>1</sup>, CHEN Bin<sup>-</sup>kai<sup>1</sup>, FU Chun<sup>-</sup>yang<sup>2</sup>

（1. School of Economics，Central University of Finance and Economics；

2. School of Economics，University of Chinese Academy of Social Sciences）

<sup>Abstract：</sup> In recent years<sup>，</sup> quantitative spatial equilibrium models <sup>（</sup>QSM<sup>）</sup> have been rapidly developed and popularized. Compared with traditional empirical and theoretical methods, QSM's advantage lies in the general equilibrium effect<sup>，</sup>based on which we could proceed abundant quantitative counterfactual analysis and policy simulations. In addition<sup>，</sup>by match multi<sup>-</sup>dimensional data<sup>，</sup>QSM is able to contribute rich and credible quantitative analysis.

With the interdisciplinary applications of QSM<sup>，</sup>this research paradigm is incorporating the feature of dynamics. There are at least three necessities for dynamic quantitative spatial equilibrium models (DQSM). First, for some economic disciplines, dynamic frameworks have long been the fundamental paradigm<sup>，</sup>such as contemporary macroeconomics and financial economics. Second<sup>，</sup>for some research obiects, their own attributes naturally include intertemporal characteristics, such as real estate with durability and investment attributes<sup>，</sup>and education migration that affects intergenerational mobility. Third, for some events , the evolution process may be slow, resulting in different short-term and long-term impacts<sup>，</sup>such as the cost<sup>-</sup>benefit consideration of infrastructure construction<sup>，</sup>and the long<sup>-</sup>term and short term impacts of environmental changes.

Currently<sup>，</sup>there have been literature reviews on QSM. However<sup>，</sup>for DQSM<sup>，</sup>to the best of the author's knowledge, no literature has given a comprehensive and detailed review. In addition, the application of DQSM among Chinese academia has not yet officially started. This paper attempts to fill these two gaps.

This paper firstly outlines the theoretical framework of DQSM, including labor dynamics, capital dynamics<sup>，</sup>firm dynamics<sup>，</sup>and other modules. Secondly<sup>，</sup>this paper explains the key difficulties in introducing spatial dynamics<sup>，</sup>and points out that the<sup>“</sup>curse of dimensionality<sup>”</sup>caused by the interaction of spatial and temporal dimensions in numerical simulation is the main technical difficulty. Thirdly, this paper reviews the application topics of DQSM. We find that DQSM has long ceased to be an exclusive research tool in the three fields of regional economy, urban economy and international trade. It has shown strong applicability in macroeconomics<sup>，</sup>development economics<sup>，</sup>financial economics<sup>，</sup>environmental economics, real estate economics , and other disciplines.

Then<sup>，</sup>as an application illustration<sup>，</sup>this paper applies DQSM to China’s macro<sup>-</sup>economy<sup>，</sup>which not only gives a detailed demonstration of modeling, algorithm , data matching, and simulation, but also proposes new perspectives and new discoveries given by this new framework. It is found that the convergence rate of the economic system drops significantly after the introduction of population migration. In addition, the economic system does not necessarily change monotonically during the dynamic process of converging to a steady state. These findings challenge the typical macro<sup>-</sup>paradigm which relies on the analysis of the steady-state (or balanced growth path). In a further step, this paper finds that it is not capital accumulation but population distribution that ultimately determines the economic structure. With the gradual agglomeration of the population<sup>，</sup>the allocation efficiency of labor will be improved<sup>，</sup>and the level of per capita income will demonstrate regional convergence. The corresponding policy implication is that China should get rid of its over-reliance on physical capital investment, and in the context of the gradual dissipation of the “demographic dividend" , the “new demographic dividend" should be stimulated by improving the allocation efficiency of labor, especially by guiding the population to gather in the advantageous areas.

Finally, as a conclusion, this paper discusses the broad application prospects of DQSM in various China's major domestic economic topics, such as the construction of the national unified market as well as the new development pattern<sup>，</sup> broad macro<sup>-</sup>development issues<sup>，</sup> housing price divergence<sup>，</sup> and <sup>“</sup>carbon<sup>-</sup>peak/carbon<sup>-</sup>neutrality<sup>”</sup>goals.
